Ты проверяешь качество звука RVCMac на регрессии.

Порядок работы:
1. Собери проект и прогони офлайн-харнесс на всём наборе `TestAudio/` с конфигурацией из задачи (если выходы уже готовы и указаны в задаче, повторно не запускай). Для порогов нужны сиды 1 и 2 (`--seed`); сид по умолчанию равен 1.
2. Посчитай метрики `docs/SPEC_030.md`, раздел 6.2, скриптом `scripts/quality_gate.py` (как запускать — в его заголовке). `--a` — кандидат, `--b` — эталонные выходы той же конфигурации и того же режима. Определения метрик не меняй. Не складывай временные файлы в репозиторий.
3. Применяй пороги из `docs/BENCHMARKS.md`, раздел «Пороги качества», включая правило повторного прогона на другом сиде. Правило внутри скрипта — старое сравнение режимов, для регрессий его не используй. Эти пороги не подходят для сравнения разных режимов.

Отчёт:
- итог в первой строке: PASS / FAIL;
- таблица по каждому файлу и метрике;
- для FAIL: какой файл, какая метрика, на сколько хуже, и в какой части записи (таймкод).

Код приложения не меняй.
